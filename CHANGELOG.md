# Changelog

All notable changes to `filament-math-rich-editor` will be documented in this file.

## v1.0.0 - 2026-01-13

### Initial Release

- ✨ Tiptap-based math editor for Filament v4
- ✨ KaTeX integration for beautiful math rendering
- ✨ Keyboard shortcut: `Cmd/Ctrl + Shift + M`
- ✨ Input rules: `$...$` and `$$...$$` auto-conversion
- ✨ Live LaTeX preview in modal
- ✨ Offline support with bundled assets
- ✨ JSON storage for structured data
- ✨ Click-to-edit existing math nodes
- ✨ Configurable KaTeX settings
- ✨ Lazy asset loading
